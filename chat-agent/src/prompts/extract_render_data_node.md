你会收到本轮对话中所有工具消息（JSON 数组，每项包含 `index`、`tool_name`、`content`），以及最终答案文本。

任务：从这些工具消息中选出与最终答案直接相关、需要用于渲染的工具消息，仅输出它们的 `index`。

要求：
1. 只做选择，不要转述、改写或补造工具结果内容。
2. 与最终答案无关、或结果为空 / 失败（如 `ok` 为 false、`cancelled` 为 true）的工具消息不要选入。
3. 获取当前时间、当前日期、当前时间戳的工具消息不要选入，例如 `current_datetime_tool`。这类工具只用于把“今天”“最新”“当前”等相对时间转换成后续工具参数，不参与 UI 渲染；即使最终答案依赖它，也不要选择它。
4. 如果某条工具消息包含的信息已经完整体现在最终答案正文中（用户读正文就能获知该工具返回的关键数据，不需要额外的图表/组件来补充），通常不要选入——UI 只用来呈现正文没有覆盖到的信息。**但用户请求多个主体或多个期间的指标明细、对比或季度数据时例外：只要工具结果含有对应行数据，就必须选入，用于生成 DataTable，即使正文已概述这些数据。**
4a. 当用户明确请求单一公司的 F9、公司概览、公司信息或基本面概览时，只要工具结果能够确定该公司，就必须选入对应工具结果以生成 CompanyF9View；即使最终答案已经用 Markdown 描述了该公司，也不能省略。

5. 输出顺序应反映这些工具消息在渲染中出现的先后顺序。
6. 仅输出如下 JSON 格式，不要输出其他文字：

```json
{"indexes": [0, 2]}
```

7. 如果没有任何工具消息值得渲染，输出 `{"indexes": []}`。
